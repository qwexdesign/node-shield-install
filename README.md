# node-shield — установка

Загрузчик для закрытого репозитория NODE SHIELD. Самого скрипта здесь нет — только вход
в GitHub и скачивание. Поставить скрипт может только тот, кому владелец выдал доступ.

```bash
curl -fsSL https://raw.githubusercontent.com/qwexdesign/node-shield-install/main/install.sh | bash
```

Не под root — `... | sudo bash`.

## Что произойдёт

1. На экране появится ссылка `github.com/login/device` и код из 8 символов.
2. Откройте ссылку на телефоне или компьютере, где вы вошли в GitHub, введите код и нажмите **Authorize**.
3. Загрузчик скачает установщик из закрытого репозитория, тот поставит скрипт
   в `/usr/local/sbin/node-shield` и откроет меню.

Токен, который выдаёт GitHub, живёт только в памяти загрузчика и никуда не записывается.
После установки доступ приложению можно отозвать: <https://github.com/settings/applications>.

## Параметры

```bash
... | bash -s -- --version v2.10.0   # конкретный релиз
... | bash -s -- --no-run            # только поставить
... | bash -s -- --check             # какая версия стоит и какая последняя
```

Обновление — та же команда ещё раз.

«У вашего аккаунта нет доступа» — попросите владельца добавить вас в репозиторий и примите
приглашение на github.com.
